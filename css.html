🎓 O Guia Definitivo de Sobrevivência: HTML5 Semântico e CSS


Este guia reúne toda a estrutura teórica e prática necessária para o desenvolvimento web moderno, otimização de SEO, acessibilidade e exames técnicos.

🎨 1. Propriedades CSS (Estilização e Layout)

No CSS, manipulamos propriedades para alterar o visual das caixas geradas pelo HTML.

📦 Modelo de Caixa e Espaçamento

Propriedade O que ela faz (Resumido) 💡 Macete / Regra de Ouro
width Defina a largura do elemento. Você pode usar pixels (px), porcentagem (%) ou largura da tela (vw).
height Defina a altura do elemento. Evite alturas fixas em caixas de texto para que o conteúdo não transborde.
padding Espaço interno do elemento. Afaste o conteúdo (texto/imagem) da borda da própria caixa.
margin Espaço externo do elemento. Criar uma zona de separação entre caixas vizinhas.
border Crie uma borda ao redor da caixa. Sintaxe rápida: tamanho estilo cor (Ex: 2px solid red).
box-sizing Altere o cálculo do tamanho da caixa. Use sempre border-box para que o preenchimento não esticar o tamanho total.

🔤 Texto e Tipografia

Propriedade O que ela faz (Resumido) 💡 Macete / Regra de Ouro
color Altera a cor do texto. Aceitam nomes (red), Hexadecimal (#FF0000) ou RGB.
font-family Defina uma fonte (caligrafia). Sempre coloque uma fonte genérica no final (Ex: Arial, sans-serif).
font-size Altere o tamanho da letra. Use rem em vez de px para garantir acessibilidade no zoom do navegador.
font-weight Altere o peso/gordura da letra. bold deixa em negrito, normal retire o negrito.
font-style Defina o estilo da fonte. Muito usado com o valor italic (itálico).
text-align Alinha o texto no bloco. Valores comuns: left, right, center e justify.
text-decoration Adicionado ou removido traços no texto. Use none para remover o sublinhado padrão de links (<a>).
line-height Defina o espaçamento entre linhas. Melhora a leitura de parágrafos longos (um bom valor é entre 1.5 e 1.6).
letter-spacing Espaçamento entre as letras. Ótimo para dar elegância aos títulos em caixa alta.

🎨 Cores, Fundos e Efeitos

Propriedade O que ela faz (Resumido) 💡 Macete / Regra de Ouro
background-color Altere o fundo do elemento. Só pinta a área interna da caixa (incluindo o preenchimento).
background-image Aplica uma imagem de fundo. Solicite uma sintaxe url('caminho-da-imagem').
background-size Controla o tamanho da imagem de fundo. Use cover para preencher o elemento sem distorcer a imagem.
opacity Altere a transparência total. Varia de 0 (invisível) a 1 (totalmente opaco). Afeta os filhos também.
border-radius Arredonda os cantos da caixa. Use 50% em caixas perfeitamente quadradas para criar círculos.
box-shadow Aplica sombra na caixa. Sintaxe: deslocamento-x deslocamento-y desfoque cor.
cursor Altere o toque do mouse. Use pointer em elementos clicáveis que não sejam links nativos.
transition Suaviza a mudança de propriedades. Cria animações simples ao interagir com o elemento.

🧱 Layout e Posicionamento Avançado

Propriedade O que ela faz (Resumido) 💡 Macete / Regra de Ouro
display Defina o comportamento do elemento. block, inline, flex ou grid.
position Regras de posicionamento na tela. static (padrão), relative, absolute, fixed.
top / left Movem elementos posicionados. Só funciona se o elemento tiver position diferente de static.
z-index Ordem da camada visual (eixo Z). Os números maiores ficam por cima. Só funciona com position.
justify-content Alinha itens no eixo principal. No Flexbox padrão, controla o alinhamento horizontal.
align-items Alinha itens no eixo secundário. No Flexbox padrão, controla o alinhamento vertical.
gap Espaçamento entre subelementos. Funciona dentro de contêineres display: flex ou grid.

🧩 2. Estrutura Global e Semântica do HTML5

O HTML5 foca no significado (semântica) do código para ajudar motores de busca (SEO) e leitores de tela.

🌐 Estrutura Base

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<!DOCTYPE html> Declara que o documento é HTML5. Deve ser obrigatoriamente a primeira linha do código. Não possui fechamento.
<html> Raiz do documento HTML. Sempre adicione lang="pt-br" para evitar que o ouvinte produza tradução.
<head> Metadados e configurações. Tudo aqui dentro é invisível para o usuário final da página.
<body> Conteúdo visível da página. Só pode existir um por página. Guarda toda a interface do site.
<meta> Informações técnicas da página. <meta charset="UTF-8"> evita erros de acentuação e caracteres estranhos.
<title> Título da página. Define o texto que aparece na aba do navegador e nos resultados do Google.
<link> Vincula arquivos externos. Usado no <head> para conectar arquivos de estilo CSS externos.
<script> Vincula ou escreve JavaScript. Use o atributo defer para carregar o script sem travar a renderização.

📦 Blocos Estruturais (Layout Semântico)

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<header> Cabeçalho do site ou de uma seção. Costuma abrigar logotipo, título principal e menu de navegação.
<nav> Conjunto de links de navegação. Use apenas para os menus principais do site.
<main> Conteúdo principal da página. Só pode existir uma <main> por página web.
<section> Agrupar conteúdos temáticos. Quase sempre exige um título (<h2>-<h6>) dentro.
<article> Conteúdo exclusivo e independente. Se removido e colado em outro lugar, ainda mantém sentido.
<aside> Conteúdo periférico ou lateral. Usado para barras laterais, anúncios ou curiosidades.
<footer> Rodapé da página ou seção. Guarda direitos autorais, contato, políticas e links finais.
<div> Bloco genérico sem semântica. Use apenas para design/CSS quando nenhuma tag semântica servir.

🔤 3. Elementos de Conteúdo, Texto e Formatação

Tags para estruturar o fluxo de leitura e dar destaque semântico a trechos de texto.

📝 Textos e Listas

Marcação O que faz 💡 Macete / Regra de Prova
<h1> Título principal da página. Regras de SEO: Use apenas uma por página para indicar o assunto principal.
<h2>...<h6> Subtítulos hierárquicos. Nunca pule etapas (Ex: do <h2> para <h4>). Siga a ordem do documento.
<p> Cria um parágrafo de texto. Não use tags <p> vazias para pular linhas. Espaçamento é papel do CSS.
<a> Cria hiperlinks. Para abrir em nova aba use target="_blank". Sempre adicione rel="noopener".
<span> Elemento de linha sem semântica. Usado para envolver palavras isoladas dentro de um texto e estilizar com CSS.
<ul> Lista não ordenada (com bolinhas). Os únicos filhos diretos aceitáveis são as tags <li>.
<ol> Lista ordenada (numerada). Ideal para sequências lógicas, tutoriais passo a passo e rankings.
<li> Item de uma lista. Só pode existir se estiver contido dentro de uma <ul> ou de uma <ol>.
<br> Quebra de linha forte. Use apenas onde a quebra faz parte do conteúdo (Ex: poemas ou endereços).

🔬 Formação Avançada e Científica

Tags avançadas que combinam semântica, formatação e acessibilidade para conteúdo técnico.

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<strong> Define importância forte (negrito). Não use só pela estética. Indica termos cruciais para leitores de tela e SEO.
<em> Dá ênfase ao texto (itálico). Altera a entonação da voz em softwares de leitura para pessoas cegas.
<mark> Destaca texto com fundo amarelo. Funciona como um texto físico. Indica termos relevantes em buscas.
<code> Formato trechos de código de computação. Aplica uma fonte monoespaçada (onde todas as letras têm a mesma largura).
<pre> Texto pré-formatado. Mantenha todos os espaços em branco e quebras de linha digitadas no código original.
<sub> Texto subscrito (abaixo da linha). Usado em notações químicas (Ex: o número 2 na tag gera H₂O).
<sup> Texto sobrescrito (acima da linha). Usado em equações matemáticas ou dados (Ex: o número 2 na tag gera X²).
<time> Identificar datas e horários. Solicite o atributo datetime no formato internacional (Ex: datetime="2026-05-17").

📸 4. Mídias, Gráficos e Incorporações

Tags para inserção de elementos visuais e conteúdos externos.

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<img> Insere uma imagem na página. Obrigatório: o atributo alt com a descrição da imagem para acessibilidade.
<video> Exibe um player de vídeo nativo. Adicione o atributo controls para o usuário ter os botões Play e Pause.
<audio> Exibe um player de áudio nativo. Assim como o vídeo, é necessário fazer atributo controls para ficar visível na tela.
<picture> Carrega imagens responsivas. Altera a fonte da imagem dependendo do tamanho da tela (celular vs desktop).
<figure> Agrupa uma mídia e sua legenda. Usado para isolar ilustrações, fotos, diagramas ou trechos de códigos.
<figcaption> Legenda do elemento <figure>. Deve ser colocado obrigatoriamente dentro da tag <figure>.
<canvas> Área de desenho via JavaScript. Baseado em pixels (raster). Perde qualidade ao aumentar. Usado para jogos 2D.
<svg> Renderização gráfica. Baseado em equações matemáticas. Tem qualidade infinita e aceita estilos CSS.
<iframe> Incorporar outra página web. Abre uma janela para um site externo (muito usado por mapas e vídeos externos).

📝 5. Formulários, Entradas e Validação Nativa

O HTML5 possui um sistema de validação que roda direto no navegador, dispensando códigos complexos de JavaScript para validações básicas.

📋 Elementos de guarnição

Etiqueta / Atribuição O que faz (Resumido) 💡 Macete / Regra de Prova
<form> Defina uma área do formulário. Todos os dados para envio devem ser mapeados nesta tag.
<input> Campo de entrada de dados genérico. Altere o comportamento mudando o atributo type (text, password, email).
<label> Rótulo/Texto descritivo do campo. Use o atributo for com o mesmo valor do id input para vinculá-los.
<textarea> Campo de texto de múltiplas linhas. Permite redimensionamento nativo pelo usuário (pode ser travado via CSS).
<button> Elemento interativo. Dentro de um <form>, seu tipo padrão é type="submit" (envia os dados).
<select> Cria uma lista suspensa (menu suspenso). Funciona como um contêiner para agrupar as opções de escolha.
<option> Opção de escolha do <select>. Use o atributo value para definir o dado real que será enviado ao servidor.

🛠️ Atributos de Validação Nativa

Atribuição O que faz (Resumido) 💡 Macete / Regra de Prova
required Torna o preenchimento obrigatório. Impede o envio do formulário se o campo estiver em branco.
pattern Valide usando Expressões Regulares. Força formatos específicos como CPFs, telefones ou CEPs (Regex).
min / max Defina limites numéricos ou de dados. Restrinja valores mínimos e máximos aceitáveis no campo.
step Defina o intervalo de incremento. Ex: step="0.01" permite que campos numéricos aceitem decimais (dinheiro).
autofocus Foca o campo ao carregar a página. Boa prática de experiência: use em apenas um campo por página.
placeholder Texto de ajuda temporária. Parece assim que o usuário começa a digitar no campo. Não substitua um label.
readonly Bloqueia edição, mas envia o dado. O usuário lê, não altera, mas o dado é enviado na submissão do formulário.
disabled Desativa o campo e bloqueia o envio. Pegadinha de prova: o campo fica cinza e o dado NÃO é enviado ao servidor.

🛠️ 6. Atributos Globais e Tags Interativas

Recursos modernos do HTML5 que adicionam comportamento dinâmico e controle de acessibilidade diretamente na marcação.

🌍 Atributos Globais (funcionam em QUALQUER tag)

Atribuição O que faz (Resumido) 💡 Macete / Regra de Prova
id Identificador exclusivo do elemento. Regra absoluta: nunca repita o mesmo nome id na mesma página.
class Identificador reutilizável. Pode ser aplicado em múltiplos elementos para agrupá-los no CSS.
data-* Armazena dados personalizados ocultos. Substitua o * por qualquer nome (Ex: data-produto-id="45"). Lido via JS.
contenteditable Permite ao usuário editar o texto. Transforma elementos estáticos (como <p> ou <h2>) em campos editáveis.
draggable Define se o elemento é arrastável. Ativa a API nativa de arrastar e soltar do navegador (Drag and Drop).
hidden Oculta o elemento da interface. Tem o mesmo efeito prático que aplicar display: none no CSS.
tabindex Controle a navegação através da tecla TAB. 0 não inclui fluxo comum; -1 remove a seleção de foco do teclado.

⚡ Tags Interativas Nativas (Funcionam sem JavaScript)

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<details> Cria um menu retrátil (efeito sanfona). Esconde ou exibe blocos de conteúdo baseados no clique do usuário.
<summary> O título do <details>. Deve ser obrigatoriamente o primeiro elemento dentro de <details>.
<dialog> Janela modal/popup nativa. Exibe caixas de alerta ou confirmação centralizadas. Aberto via JS com .showModal().
<progress> Barra de progresso visual. Indica a conclusão de uma tarefa usando os atributos value e max.
<meter> Barra de medição escada. Usada para exibir precisão fracionada dentro de limites conhecidos (Ex: uso de CPU).

📊 7. Estruturação de Tabelas

Montar tabelas no HTML exige uma ordem de tags muito específica. Os professores mudam a ordem delas para ver se você conhece a posição.

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<table> Crie o contêiner principal da tabela. Tudo relacionado à tabela deve estar dentro dela.
<caption> Defina o título ou legenda da tabela. Regra estrita: Se for usado, deve ser obrigatoriamente a primeira tag dentro de <table>.
<thead> Agrupa o cabeçalho da tabela. Guarda a linha que diz o nome das colunas.
<tbody> Agrupa o corpo/conteúdo da tabela. É onde ficam os dados principais e a maior parte das linhas.
<tfoot> Agrupa o rodapé da tabela. Usado para totais, médias ou resumos de dados.
<tr> Cria uma linha na tabela. Funciona como um contêiner de linha. Você só pode colocar <th> ou <td> dentro dela.
<th> Crie uma célula de cabeçalho (cabeçalho da tabela). O texto aqui dentro fica automaticamente em negrito e centralizado. Só deve ser usado dentro do <thead>.
<td> Crie uma célula de dado comum (Dados da Tabela). É a célula normal da tabela. Usada dentro do <tbody> e <tfoot>.

⚠️ Pegadinha Clássica de Prova sobre Tabelas:
Para juntar duas colunas, usa-se o atributo colspan="2" na tag <td>. Para juntar duas linhas, usa-se rowspan="2"
Eles não são tags, são atributos!

🔤 8. Citações e Termos Técnicos Raros

Essas tags raramente são usadas no dia a dia, mas caem em provas teóricas para testar quem decorou o manual do HTML5.

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<abbr> Identifique uma abreviação ou sigla. Obrigatório: Use o atributo title para dizer o significado. Ex: HTML. Quando o usuário passa o mouse, o significado aparece.
<blockquote> Cria uma citação longa em bloco de outro site/autor. O navegador joga o texto um pouco para a direita (recuo automático). Você pode usar o atributo cite="link" para dizer de onde tirou.
<q> Cria uma citação curta dentro de um parágrafo. Macete visual: o navegador coloca aspas ("") automaticamente ao redor do texto. Você não precisa digitá-los.
<cite> Definir o título de uma obra (livro, filme, música). O navegador geralmente deixa o texto em itálico automaticamente.
<dfn> Indica a palavra que está sendo definida na frase. Usado em glossários ou dicionários online.
<kbd> Representa uma tecla do teclado que o usuário deve apertar. Ex: Pressione Ctrl + C. O navegador muda a fonte para parecer uma tecla de computador.
<samp> Exibe a saída/resposta de um programa de computador. Usado para mostrar mensagens de erro de sistemas ou logs de terminal.
<var> Defina uma variável em matemática ou programação. O texto fica em itálico para parecer uma variável de inovação (Ex: x = 10).

⚙️ 9. Scripts, Shadow DOM e Fallbacks

Tags de controle técnico que lidam com navegadores antigos, segurança ou programação avançada de componentes.

Marcação O que faz (Resumido) 💡 Macete / Regra de Prova
<noscript> Exibe uma mensagem se o JavaScript estiver desativado. Se o usuário bloquear o JavaScript no navegador, aparecerá o texto dentro dessa tag (Ex: "Ative o JavaScript para ver este site"). Se o JS estiver ativo, ela não é exibida.
<template> Guarde um código HTML que fica oculto. O navegador lê o código, mas não exibe na tela até que um script de JavaScript "ordene" que ele seja aplicado. Útil para clonar elementos clonáveis.
<slot> Crie um espaço reservado dentro de um Web Component. Usado em programação avançada (Shadow DOM) para criar componentes reutilizáveis onde você pode inserir textos diferentes depois.
<map> Crie um mapa de links em cima de uma imagem. Permite mapear áreas de uma foto para que cada pedaço dela leve um link diferente. Funciona junto com a tag <area>.
<area> Defina os pontos clicáveis dentro da tag <map>. Usa atributos de geometria como shape="circle" ou shape="rect" e coordenadas (coords) para desenhar onde o clique funciona.
