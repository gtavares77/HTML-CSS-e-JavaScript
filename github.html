Git e GitHub

🧠Subir projeto GitHub!

Git: É o sistema que fica instalado no seu computador controlando as versões do código (como se fosse o botão "Salvar Histórico").

GitHub: É o site (a nuvem) onde você guarda os projetos que o Git controla, permitindo que outras pessoas vejam ou que você trabalhe em equipe.

🚀 PASSO A PASSO COMPLETO (DO ZERO AO PUSH)

Segue exatamente na ordem 👇

🟢 1. Criar repositório no GitHub

  • 1. Acesse o GitHub
  • 2. Clique em New repository
  • 3. Crie seu projeto

💻 2. Entrar na pasta do projeto

No terminal: no vscode.


cd caminho/da/sua/pasta

⚙️ 3. Iniciar o Git: no terminal dentro do vscode.

git init

📦 4. Adicionar arquivos

git add .

💾 5. Criar o commit (OBRIGATÓRIO)

git commit -m "Mensagem do commit"

📤 6. Conectar o repositório: (link la no GitHube)

git remote add origin https://github.com/SEU-USUARIO/NOME-DO-REPO.git

👉 Se já tiver errado antes, corrige com :

git remote set-url origin https://github.com/SEU-USUARIO/NOME-DO-REPO.git

🔍 7. Verificar branch

git branch

👉 Vai aparecer:

* main

OU

* master

🚀 8. Enviar para o GitHub (PUSH)

👉 Se for master:

git push origin master

👉 Se for main:

git push origin main

🔄 9. Depois (pra atualizar o projeto)

Sempre que mudar algo :

git add .

git commit -m "Mensagem do commit"

👉 Se for main:

git push origin main

⚡ CHECKLIST RÁPIDO (ANTI-ERRO)

  • ✔ Fiz git init
  • ✔ Fiz git add .
  • ✔ Fiz git commit
  • ✔ URL do repositório está correta
  • ✔ Sei se é main ou master

🧠 DICA FINAL (nível profissional)

Se quiser evitar confusão com master:

git branch -M main

👉 Isso renomeia a branch master para main, evitando erros futuros.

Resumão

git init
git add .
git commit-m"primeiro commit"
git remote add origin https://github.com/
git branch-M main
git push-u origin main

🚀 PRONTO! Agora é só acessar seu repositório no GitHub e ver seu projeto lá! 🎉
