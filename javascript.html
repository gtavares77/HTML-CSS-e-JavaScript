2. Variáveis (Onde guardamos dados)

Comando Escopo Descrição
const Bloco Cria uma constante. O valor não pode ser alterado depois de definido.
let Bloco Cria uma variável que pode mudar de valor ao longo do código.
var Global Função Modo antigo. Evite usar porque pode causar bugs de escopo.

4. Operadores (Para fazer contas e comparações)

Aritiméticos :

  • +(Soma / Concatenar texto)
  • -(Sub)
  • *(Multiplicação)
  • /(Divisão)
  • %(Resto da)

Comparação (Retornam true ou false) :

  • == (Igual em valor, mas ignora o tipo. Ex: 5 == "5"é verdadeiro)
  • === ( Igual estrito : igual em valor E tipo. Ex: 5 === "5"é false. Use sempre este! )
  • != / !== (Diferente / Diferente estrito)
  • > / < (Maior que / Menor que)
  • >= / <= (Maior ou igual / Menor ou igual)

Lógicos :

  • && (E/AND) -> Todas as condições precisam ser verdadeiras.
  • || (OU / OR) -> Pelo menos uma condição precisa ser verdadeira.
  • ! (NÃO / NOT) -> Inverta o valor booleano.

8. Manipulação do DOM (Interagindo com o HTML da página)

Essa é a parte mais importante para quem está criando sites. É como o JS encontra e altera as coisas na tela.

Elementos :


   const botao = document.querySelector("#id-do-botao");     // Seleciona por ID (como no CSS)
const caixas =  document.querySelectorAll(".classe-caixa" ); // Seleciona vários elementos por Classe

Modificar Elementos :


   const titulo =document .querySelector("h1");

titulo.textContent ="Novo Texto do Título"; // Muda o texto interno
titulo.style.color ="blue";                // Altera o CSS diretamente
titulo.classList.add("classe-nova");        // Adiciona uma classe CSS
titulo.classList.remove("classe-antiga");   // Remove uma classe CSS

9. Eventos (Fazer o site reagir ao usuário)

Os eventos disparam funções quando o usuário faz alguma ação na página.


   const  botao =document.querySelector("#meu-botao");

    // Sintaxe: elemento.addEventListener("evento", funcao);
botao.addEventListener("click", () => {
  alert("O botão foi clicado!");
});

Principais Eventos para Sites :

  • click: Quando o usuário clica em nenhum elemento.
  • submit: Quando um formulário é enviado.
  • keydown/ keyup: Quando uma tecla é pressionada / solta.
  • mouseenter/ mouseleave: Quando o mouse passa por cima / sai do elemento.
  • DOMContentLoaded: Dispara quando a página HTML terminou de carregar completamente (ótimo para envolver seu código JS)
