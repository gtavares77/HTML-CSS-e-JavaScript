1. A Estrutura Básica Obrigatória

Todo arquivo HTML (geralmente salvo comoindex.html ) precisa começar com esta estrutura para o navegador entender o que está lendo:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Meu Site Colorido</title>
<link rel="stylesheet" href="style.css">
</head>
<body>

</body>
</html>

2. Tags Semânticas (Estrutura e SEO)

As tags semânticas servem para explicar ao Google e aos leitores de tela o que cada parte do site representa. Evite criar um site feito apenas de <div> .

Marcação O que ela representa?
</header> O topo do site (onde costuma ficar o logotipo e o menu principal).
<nav> Bloco de links de navegação (menus).
<main> O conteúdo principal e exclusivo daquela página. (Só deve existir um por página).
<section> Uma seção genérica de conteúdo (ex: Seção "Sobre Nós", Seção "Serviços").
<article> Um conteúdo que faz sentido sozinho (ex: um post de blog, uma notícia).
<aside> Conteúdo lateral ou periférico (barras laterais, anúncios, links relacionados).
<footer O rodapé do site (direitos autorais, links secundários, contato).
<div> Uma caixa genérica sem significado. Use apenas para fins de design/CSS.

7. Recursos Modernos e Nativos

O HTML moderno impede a necessidade de usar JavaScript para coisas simples. Veja duas tags excelentes e muito suportadas hoje em dia:

Uma Tag <dialog>(Modais/Popups Nativos)

Crie uma janela de diálogo por cima do site sem precisar de bibliotecas externas complexas.


        <dialog id="meuModal">
        <p>Este é um popup nativo super leve!</p>
        <button onclick="document.getElementById('meuModal').close()">Fechar</button>
        </dialog>

O Atributo popover

Qualquer elemento (como uma divou um p) pode virar um popover que aparece e desaparece automaticamente ao clicar em um botão específico, sem nenhuma linha de JavaScript.


    <button popovertarget="meu-popover">Ver Dica</button>

  <div id="meu-popover" popover>
    <p>Esta é a informação flutuante!</p>
  </div>

💡 Dica de ouro: Sempre feche suas tags (ex: <div> ... </div>). As poucas tags que não precisam de fechamento são chamadas de autofechamento , como <img>, <input>, <br>e <hr>. Preparar um resumo com todas as tags do HTML5 organizado por categorias é a melhor forma de criar um "buscador de bolso" perfeito.

Aqui está o seu mapa completo e definitivo das tags do HTML5:

1. Estrutura Raiz e Metadados (O esqueleto invisível)

Essas tags ficam no topo do arquivo e preparam o terreno para o navegador e para o Google entenderem seu site.

Marcação O que ela faz?
<!DOCTYPE html> Informa ao navegador que o documento é um arquivo HTML5 moderno.
<html A raiz de todo o documento. Tudo no site fica dentro dela.
<head> Guarda os metadados (informações invisíveis para o usuário, mas específicas para o navegador).
<tittle Defina o título da página que aparece na aba do navegador.
<meta> Define propriedades como codificação de texto ( charset), adaptação para celular ( viewport) e descrição para o Google.
<link> Vincula arquivos externos ao HTML (como o seu arquivo de estilos CSS ou fontes do Google).
<style> Permita escrever o código CSS diretamente dentro do arquivo HTML (evite usar muito, prefira o ).
<script> Insira ou linka códigos JavaScript na página.

2. Tags Semânticas de Layout (Uma estrutura visual)

Eles organizaram as "gavetas" do seu site, informando exatamente onde fica cada bloco de conteúdo.

Marcação O que ela faz?
<header> Defina o topo da página ou de uma seção específica (geralmente tem logotipos e menus).
<nav> Agrupa os links de navegação principal (os menus do site).
<main> Envolva o conteúdo principal e exclusivo daquela página. Só deve existir um por página.
<section> Crie uma seção lógica de conteúdo sobre um tema específico.
<article> Defina um bloco de conteúdo independente e completo (como um post de blog ou uma notícia).
<aside> Uma barra lateral com conteúdos secundários ou relacionados (anúncios, widgets).
<footer> O rodapé da página (direitos autorais, links de contato, redes sociais).
<div> Uma caixa genérica usada apenas para criar layouts ou aplicar estilos com CSS quando nenhuma tag acima faz sentido.

3. Conteúdo de Texto e Formatação

Tags usadas para estruturar e dar significado às palavras na tela.

Marcação O que ela faz?
<h1> ao <h6> Títulos do site, sendo o < h1>mais importante (use apenas um por página) e < h6>o menor.
<p> Crie um parágrafo de texto comum.
<strong> Destaca um texto dando a ele forte importância (o navegador aplica-se negro).
<em> Dá ênfase a um termo (o navegador aplicado itálico).
<small> Usado para textos secundários, como letrinhas miúdas de contratos ou direitos autorais.
<code> Formato o texto como código de programação (muda a fonte para monoespaçada).
<pre> Exibe o texto exatamente como foi digitalizado no editor, respeitando espaços e quebras de linha.
<blockquote> Usado para indicar uma citação longa de outra fonte.
<span> Uma marcação em linha genérica, usada para isolar trechos de texto e aplicar estilos específicos via CSS.
<br> Quebra a linha do texto obrigatoriamente.
<hr> Cria uma linha divisória horizontal para separar conteúdo.

4. Links, Listas e Tabelas

Links

  • <a>: Cria links para outras páginas ou sites (use o atributo href=""para o destino).

Listas

  • <ul>: Crie uma lista não ordenada (com bolinhas).
  • <ol>: Cria uma lista ordenada (numerada automaticamente: 1, 2, 3...).
  • <li>: Define cada item de uma lista (usado dentro de <ul>ou <ol>).

Tabelas

  • <table> Cria a estrutura da tabela.
  • <thead> Grupo o cabeçalho da tabela.
  • <tbody> Agrupa o corpo com os dados principais da tabela.
  • <tfoot> Agrupa o da tabela.
  • <tr> Cria uma linha na tabela.
  • <th> Crie uma célula de título (negrito e centralizado).
  • <td> Cria uma célula de dado comum.

5. Mídias e Incorporação (Imagens e Vídeos)

Para deixar o site visualmente rico e interativo.

Marcação O que ela faz?
<img> Exibe uma imagem na tela (usa os atributos srcpara o caminho e altpara a descrição).
<video> Adiciona um player de vídeo nativo (use o atributo controlspara liberar o play/pause).
<audio> Adicionado um player de áudio nativo na página.
<source> Defina os arquivos de mídia e formatos para as tags < video>ou < audio>.
< iframe> Incorpora outra página web inteira dentro do seu site (muito usada para mapas do Google ou vídeos do YouTube).
< pictures> Permite carregar imagens diferentes dependendo do tamanho da tela do usuário (ótimo para performance).
< figure> Agrupa uma imagem/ilustração e sua legenda explicativa.
< figcaption A legenda da imagem, usada obrigatoriamente dentro da tag < figure>.

6. Formulários e Elementos de Entrada

Para coletar dados, mensagens e interações dos usuários.

Marcação O que ela faz?
< form> Crie uma área do formulário que irá agrupar os campos de envio.
< label> Crie uma etiqueta/texto explicativo para um campo de digitação.
< imput> O campo onde o usuário digital. O tipo muda de acordo com o atributo type(ex: type="text", type="password", type="email", type="date").
< textarea> Caixa de texto grande de várias linhas (ideal para mensagens ou comentários).
< botton> Crie um botão clicável (use type="submit"para enviar formulários).
< select> Crie uma lista de seleção de estilo no menu flutuante (suspenso).
< option> Defina cada uma das opções dentro do < select>.
< fildset> Desenha uma borda para agrupar campos relacionados dentro de um formulário.
< legend> Dá um título para o grupo criado pelo < fieldset>.

7. Interatividade Avançada (Recursos Modernos do HTML5)

Tags que dão superpoderes ao site de forma nativa.

Marcação O que ela faz?
< details>/th> Crie um bloco de conteúdo retrátil que o usuário pode abrir ou fechar clicando nele (estilo sanfona/FAQ).
< summary> O título visível que o usuário clicou para abrir uma tag < details>.
< dialog Cria uma janela de popup/modal nativa, controlada facilmente por JS.
< canvas> Uma área em branco usada para desenhar gráficos, animações ou jogos diretamente via JavaScript.
< progress Exiba uma barra de progresso visual (útil para uploads ou etapas de um formulário).
< meter> Exibe uma barra de medição dentro de um intervalo conhecido (ex: uso de espaço em disco).
